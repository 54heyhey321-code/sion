# 찰랑찰랑

태블릿에서 한 기기로 즐기는 2~3인용 순서제 물 채우기 게임입니다.

## 실행

index.html을 브라우저로 열면 바로 실행됩니다. 설치나 빌드가 필요하지 않습니다.

## 게임 방법

1. 2인 또는 3인을 선택합니다.
2. 자기 차례에 수도꼭지나 물 채우기 버튼을 누르고 있습니다.
3. 손을 떼면 물이 멈추고 다음 플레이어 차례로 넘어갑니다.
4. 다음 플레이어가 준비 완료를 누르고 이어서 진행합니다.
5. 물을 넘치게 한 플레이어가 패배합니다.

키보드에서는 스페이스를 누르고 있어도 물을 채울 수 있습니다.
